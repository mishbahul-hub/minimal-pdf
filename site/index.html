Minimal PDF

A fast, keyboard-first PDF reader for Windows where the page is the whole interface.

Download for Windows View on GitHub

Free and open source · ~8 MB · Windows 10 and 11

Opens instantly

Only the pages on screen are drawn, so a 500-page book scrolls as smoothly as a 5-page one.

No toolbar

Search, contents and tools appear when you ask for them and close with Esc.

Keyboard first

j k to scroll, / to search, t for contents, ? for everything else.

Your files stay yours

Annotations are kept separately. Your PDF only changes if you choose to save them into it.

Annotate from a ring around your cursor

Right-click anywhere: pen, highlighter, pencil, shapes, eraser and text comments, with colours and sizes on the outer ring. While you write, the cursor becomes the pen itself.

Save a new PDF with your annotations drawn in, so they show in any reader.

Ask the PDF, get answers with page numbers

Press c and ask anything. The AI searches and reads the document itself, shows each step, and cites the pages it used. Click a citation to jump there.

Works with free API keys (Google Gemini, Groq, Hugging Face, OpenRouter), fully offline with Ollama, or with Claude.

Translate into your language, offline

Select English text and translate it into Hindi, Marathi, Assamese, Bengali or Arabic, or summarise it first. The models run on your computer: no key, and your text never leaves it.

Explain, Simplify and Define are one right-click away too.

Light, dark or sepia

Questions

Is it free?

Yes, and open source under the MIT license. AI chat costs nothing with the free tiers of Gemini, Groq, Hugging Face or OpenRouter, or with Ollama on your own computer.

Windows says "Windows protected your PC". Is it safe?

The installer isn't code-signed yet, so Windows doesn't recognise the publisher. Choose More info → Run anyway. The source code and the build are public on GitHub, and updates are signed.

Does it work offline?

Reading, search, annotations and saving always work offline. Translate and Summarize work offline after a one-time model download. The chat works offline with Ollama.

Is my PDF uploaded anywhere?

No. Nothing is sent until you ask the AI something, and then only your question and the pages it reads go to the provider you chose. API keys are stored in Windows Credential Manager.

macOS or Linux?

Not yet. Windows only for now.

How do I update?

The app checks for new versions when it starts and offers Install and restart.
